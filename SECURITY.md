
# Security Policy

## Supported Versions

| Version | Status |
| ------- | ------ |
| 1.0.x | Initial development |

## Reporting a Vulnerability

If you discover a security vulnerability in WP Smart Form Protection, please report it responsibly.

Use GitHub's private vulnerability reporting feature if it is enabled.

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Affected plugin and WordPress versions.
- Potential security impact.
- Suggested fixes, if available.

Please do not publicly disclose sensitive vulnerability details before a fix is available.

## Security Practices

The project aims to follow WordPress security best practices, including:

- Input validation.
- Data sanitization.
- Output escaping.
- Secure form processing.
- Minimal external dependencies.

## Disclaimer

This plugin is currently in early development and has not undergone a formal security audit.
