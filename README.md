
# WP Smart Form Protection

A lightweight, open-source WordPress plugin designed to reduce automated spam submissions using honeypot protection.

## Overview

WP Smart Form Protection provides a simple approach to protecting WordPress comment forms from automated spam bots without requiring CAPTCHA or third-party services.

## Features

- Lightweight honeypot spam protection
- WordPress comment form integration
- Server-side form validation
- No external API dependencies
- No additional database tables
- Open-source and developer-friendly

## Installation

1. Download this repository as a ZIP file.
2. Extract the downloaded ZIP file.
3. Upload the plugin folder to wp-content/plugins/.
4. Open your WordPress admin dashboard.
5. Navigate to Plugins.
6. Activate WP Smart Form Protection.

## How It Works

The plugin adds a hidden honeypot field to WordPress comment forms. If an automated bot fills this field, the submission is rejected.
