
# Contributing to WP Smart Form Protection

Thank you for your interest in contributing to this open-source project.

## Ways to Contribute

- Report bugs and compatibility issues.
- Suggest new features.
- Improve documentation.
- Improve plugin performance and security.
- Submit pull requests.
- Help test WordPress compatibility.

## Getting Started

1. Fork this repository.
2. Clone your fork to your local machine.
3. Create a new branch.
4. Make your changes.
5. Test your changes in a WordPress development environment.
6. Commit your changes.
7. Submit a pull request.

## Coding Guidelines

- Follow WordPress coding standards.
- Write clean and readable PHP code.
- Validate and sanitize user input.
- Escape output where necessary.
- Avoid unnecessary dependencies.
- Document new functionality.

## Pull Request Guidelines

- Provide a clear description of your changes.
- Explain the problem being solved.
- Include testing details.
- Keep changes focused and relevant.

## Community Guidelines

Be respectful, professional, and supportive of other contributors.

All contributions are welcome.
